# 🚀 ElanceForge

A full-stack **Freelancing Marketplace** built using the **MERN Stack** where clients can post projects, freelancers can create gigs, submit proposals, manage orders, and communicate securely.

---

## 📌 Overview

ElanceForge is a Fiverr/Upwork-inspired freelancing platform that connects **Clients** and **Freelancers**.

Clients can post projects, hire freelancers, manage orders, and review completed work, while freelancers can create gigs, submit proposals, manage projects, and build their professional profiles.

---
